# 📚 StudyHub

**StudyHub** is a simple educational resource website made for students to find study materials, video lectures, and useful learning resources in one place.

> 🚧 This project is created mainly for **HTML practice and learning**.

## ✨ Features

* 📖 Subject-wise study material
* 🎥 Embedded video lectures
* 🔎 Search section
* 📝 Student contact form
* 📊 Tables for organizing resources
* 🔗 Links between different pages

## 📚 Subjects

* Web Development
* Computer Science
* Mathematics
* Physics

The Web Development section covers topics such as HTML, CSS, JavaScript, Git & GitHub, React.js, Node.js, Express.js, MongoDB, and MERN Stack.

## 🛠️ Technologies Used

* HTML5
* YouTube Iframes
